# 🌟 정밀 성격 유형 검사 (Advanced MBTI Platform)

이 프로젝트는 Tailwind CSS와 Vanilla JavaScript를 활용하여 개발된 현대적이고 정밀한 MBTI 심리 진단 플랫폼입니다.

## 🚀 주요 특징 및 개선 내역 (v2.5)

최근 업데이트를 통해 다음과 같은 기능들이 대폭 강화되었습니다:

### 1. 개인화된 경험 (Personalization)
- **이름 기반 진단:** 사용자 이름을 입력받아 리포트 전반에 걸쳐 맞춤형 메시지 제공.
- **사용자 인사말:** 결과 화면에서 사용자의 이름을 언급하여 몰입도 향상.

### 2. 심층 분석 데이터 (Detailed Insights)
- **커리어 로드맵:** 각 유형별 성향에 최적화된 4가지 추천 직업군 제시.
- **최고의 궁합:** 본인 유형과 가장 상성이 좋은 '환상의 짝꿍' 유형 정보 제공.
- **확장된 유형 설명:** 16개 유형의 특징, 장단점, 성장 솔루션을 더 깊이 있게 분석.

### 3. 유틸리티 및 편의성 (Utility)
- **테스트 히스토리:** `localStorage`를 활용하여 이전 테스트 결과를 브라우저에 저장하고 언제든 다시 확인 가능.
- **소셜 공유:** 결과 링크 복사 및 SNS 공유 기능을 통해 지인들과 간편하게 결과 공유.
- **스마트 스크롤:** 문항 선택 시 다음 질문으로 자동 이동하여 끊김 없는 사용자 경험 제공.

### 4. 디자인 및 UI/UX (Design)
- **Glassmorphism UI:** 최신 디자인 트렌드인 유리 질감의 패널과 유려한 그라데이션 적용.
- **반응형 디자인:** 모바일, 태블릿, 데스크탑 모든 환경에서 최적화된 화면 구성.
- **실시간 프로그레스:** 상단 게이지 바를 통해 직관적인 진척도 확인.

## 🛠 사용 기술
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
- **Storage:** Browser LocalStorage
- **Deployment:** GitHub Pages (추천)
